# Virgo-RNG — experimental SDR/entropy research toolkit

**Research software and data package, November 2026.** Main platform: **Virgo-RNG v2.0.0**. This repository contains code and archived numerical results from the E1–E7 measurement campaign near the Galactic neutral-hydrogen 21-cm line, plus supporting statistical tests.

> **Scientific status:** The spectral observations contain candidates compatible with Galactic H I emission, but their uniquely astronomical origin has **not** been demonstrated. The I/Q statistics do **not** establish astronomical causation of entropy, and the software is **not a certified TRNG**. Do not use output for cryptographic keys.

## What is here

| Path | Contents |
|---|---|
| `virgo_rng/` | Canonical Virgo-RNG v2.0.0 implementation, including the lab interface |
| `tests/` | Original platform unit/regression tests |
| `scripts/campaigns/` | E1–E7 acquisition, analysis, and resumable reprocessing tools |
| `scripts/statistics/` | Entropy, correlation, prediction, NIST-analysis wrappers and supplementary scripts |
| `scripts/from_study_v8/` | Additional archived reanalysis and audit programs |
| `legacy/virgo_rng_v1_22/` | Older experimental version snapshot; not the primary install target |
| `data/processed/` | Structured numeric results from archived campaigns and analyses (`CSV`, `JSON`, text, some numerical arrays) |
| `data/samples/` | One available small raw CU8 example, **not** the complete E1–E7 corpus |
| `data/provenance/` | Per-file SHA-256 hashes, source archives and provenance documentation |
| `docs/` | Setup, analysis procedures, data limitations, publication preparation and GitHub instructions |

No journal manuscript, LaTeX source, bibliography, manuscript figures, or hardware photos are included. Graphs can be regenerated by readers using numerical results and analysis programs. **Raw CU8 files for the full E1–E7 campaigns were not available to the packager**, and are not represented as present.

## Install (Python 3.10+)

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[test,plot]'
python -m pytest -q tests
```

For RTL-SDR capture, install an appropriate `rtl_sdr` command separately, verify driver permissions and device power, and review the equipment/safety notes before connecting bias tee and loads. No SDR is required for archived-data analysis.

## Quick examples

```bash
virgo-rng --help
virgo-rng-lab --help
python scripts/campaigns/virgo_e6_reprocessar_integral.py --help
python scripts/campaigns/virgo_e4_e5_reprocessar_integral_v2.py --help
```

For an archived data example, inspect `data/processed/E6_fullrecord/contrasts_e6_integral.csv` or `data/processed/E7_fullrecord_DC/summary_dc.json`. Reprocessing *original raw CU8* requires placing the full captures locally and supplying the directory paths as described by each script; those large files are not in this repository.

Read [dataset details](docs/DATA_AVAILABILITY.md), [reproducibility guidance](docs/REPRODUCIBILITY.md) and [Portuguese GitHub publication guide](docs/COMO_PUBLICAR_GITHUB.md).
